# Static assets

`icon-192.png`, `icon-512.png`, `icon-maskable-512.png` are **placeholder** flat
blue squares so the PWA installs. Replace with real artwork before launch
(maskable safe zone: centre 80%).

The bundled AAC symbol library (`symbols/`) is generated by
`scripts/build_symbols.py` directly into this directory — the `.svg` files
and `LICENSE` are committed, not built in CI. Source: Mulberry Symbols
(CC BY-SA 4.0), staged and reviewed via `scripts/mulberry_manifest.py` and a
published review Artifact before ingestion. See `docs/symbols.md` for the
full pipeline. `file_path` for a Mulberry row is always `<id>.svg` — flat,
no subfolders — every frontend render site depends on this; re-running the
script bumps `SYMBOLS_VERSION` in `frontend/js/ui.js` (defeats Railway's CDN
edge cache, which otherwise keeps serving old artwork under an unchanged
path for up to 7 days after a deploy).

## `symbols/pcs/` — PCS / Boardmaker set, **dev only**

`symbols/pcs/*.png` is a large PCS (Picture Communication Symbols, Mayer-Johnson
/ Tobii Dynavox) set imported by `scripts/build_pcs_symbols.py` from a
PowerPoint export the project owner supplied. **PCS is proprietary — not open
licensed.** It is bundled to unblock design/testing on `dev` and must not ship
to production without a Boardmaker content licence. `scripts/release.sh` refuses
to apply `supabase/migrations/*_pcs_symbols.sql` on the production environment.
These rows' `file_path` is `pcs/<id>.png` (the one documented exception to the
flat-`<id>.svg` rule — `ui.js`'s `symbolUrl()` handles it). See
`symbols/pcs/LICENSE.md`.
